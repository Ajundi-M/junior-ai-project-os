# Spec Kit Checklist

## Before Specification

```text
[ ] Project goal is clear
[ ] Target user is clear
[ ] Project level is chosen
[ ] Stack direction is chosen
[ ] Main feature/problem is described
```

## Specification Checklist

```text
[ ] User goal is described
[ ] Problem is described
[ ] In-scope behavior is listed
[ ] Out-of-scope behavior is listed
[ ] User stories are written
[ ] Acceptance criteria are clear
[ ] Edge cases are listed
[ ] Data/security concerns are listed
[ ] UI/UX states are considered
[ ] Success definition is clear
```

## Plan Checklist

```text
[ ] Frontend impact is described
[ ] Backend/API impact is described
[ ] Database impact is described
[ ] Auth/permission impact is described
[ ] External services are listed if needed
[ ] Testing strategy is included
[ ] Risks are listed
[ ] Dependencies are justified
```

## Task Checklist

```text
[ ] Tasks are small
[ ] Each task has a clear goal
[ ] Each task lists likely affected files
[ ] Each task has acceptance criteria
[ ] Each task has testing notes
[ ] Tasks are ordered logically
[ ] No task is too large for one focused Cursor implementation step
```

## Before Cursor Implementation

```text
[ ] I understand the spec
[ ] I understand the plan
[ ] I understand the current task
[ ] I know how to verify the task
[ ] I know what should not be changed
```
