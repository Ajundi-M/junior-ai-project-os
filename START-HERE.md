# Start Here

This is your operating system for building projects with AI.

You are a junior software engineer. That means the system should help you do two things at the same time:

1. Build professional projects.
2. Learn deeply while building.

## The most important habit

Do not start coding immediately.

Always follow this order:

```text
Understand → Clarify → Specify → Plan → Tasks → Build → Review → Test → Document → Present
```

Spec Kit owns the `Specify → Plan → Tasks` part. Cursor should not start serious implementation until those parts are clear.

## Your first decision for every project

Ask:

```text
What is the purpose of this project?
```

Choose one:

- Learning project
- Portfolio project
- Freelance/client project
- SaaS/product idea

Then choose the level:

- Level 1: Simple Portfolio Project
- Level 2: Professional Portfolio Project
- Level 3: Freelance/Client-Ready Project
- Level 4: SaaS/Product Project

For now, most of your serious projects should be Level 2.

## Where Spec Kit fits

Spec Kit happens before Cursor implementation.

Use it to answer:

```text
What exactly should be built?
How should it be built?
What small task should Cursor implement next?
```

Use Spec Kit by level:

```text
Level 1: optional lightweight specification
Level 2: standard for serious features
Level 3: required
Level 4: required
```

For a Level 1 project, a short manual spec may be enough. For Level 2 and above, write the specification, technical plan, and task list before coding.

## Your AI team

Use AI as roles:

- ChatGPT: Project Manager + Teacher
- Claude: Architect + Reviewer
- Gemini: UI/UX + visual reasoning
- Spec Kit: specification, technical plan, and task breakdown
- Cursor: implementation environment
- CodeRabbit: pull request review gate
- TestSprite: testing and QA gate

## Your rule before accepting any AI code

Before accepting generated code, ask:

```text
Can I explain what this code does?
Can I explain why this solution was chosen?
Can I connect it to the specification?
Can I test it?
Can I debug it if it breaks?
```

If the answer is no, ask AI to explain it before continuing.
