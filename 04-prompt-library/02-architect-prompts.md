# Architect Prompts

Use these prompts with ChatGPT or Claude.

---

## Stack Selection

```text
Act as a senior software architect.

Help me choose the best stack for this project.

Consider:
- project level
- target users
- required features
- auth
- database
- AI/API usage
- file uploads
- security
- deployment
- cost
- my junior skill level
- portfolio value

Compare options and recommend the simplest professional stack.
```

---

## Architecture Plan

```text
Act as a senior software architect.

Create an architecture plan for this project.

Include:
- system overview
- frontend pages
- components
- backend/API routes
- database tables
- auth flow
- user roles
- external services
- security risks
- deployment model
- testing strategy

Explain why each decision is made.
```

---

## Security Review

```text
Act as a security-minded senior engineer.

Review this project architecture/code for:
- exposed secrets
- weak auth
- missing permission checks
- database access risks
- input validation
- unsafe API routes
- logging sensitive data
- abuse/rate-limit risks

Give me:
1. Critical issues
2. Important issues
3. Nice-to-have improvements
4. Exact fixes
```
