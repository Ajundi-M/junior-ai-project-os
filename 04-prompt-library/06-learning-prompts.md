# Learning Prompts

Use these to make sure you are learning, not just generating code.

---

## Explain Feature

```text
Explain this feature to me as a junior software engineer.

Include:
- what it does
- what files are involved
- how data flows
- why this approach was used
- what could break
- how to debug it
```

---

## Interview Explanation

```text
Help me explain this project feature in a job interview.

Make it sound professional but honest for a junior developer.

Include:
- problem
- solution
- stack
- tradeoffs
- what I learned
```

---

## Learning Notes

```text
Create learning notes for what I just built.

Include:
- concepts used
- important files
- important functions/components
- mistakes to avoid
- questions I should be able to answer
```
