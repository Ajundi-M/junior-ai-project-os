# Cursor Instructions for This Playbook

When using Cursor with this folder or with a project created from this system:

1. Do not implement large features in one step.
2. Always work from a task file or clear task description.
3. For Level 2+ work, implementation should come from a Spec Kit specification, technical plan, and task list.
4. Do not implement from vague feature ideas.
5. If a task is unclear, ask for the related specification or technical plan before coding.
6. Use the Spec Kit task as the source of truth.
7. Keep code changes traceable to the specification.
8. Follow the project constitution.
9. Ask before adding new dependencies.
10. Keep code readable for a junior developer.
11. Explain changed files after implementation.
12. Do not expose secrets.
13. Include loading, empty, and error states when relevant.
14. Suggest tests for important logic.
15. Remind the developer to run CodeRabbit and TestSprite before accepting important features.
